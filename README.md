# Prototipo App Mobile - Jeno's Pizza

Prototipo funcional en React + Vite para simular el flujo de ingreso, pedido y línea de tiempo de preparación de una orden de Jeno's Pizza.

## Estructura correcta para GitHub

```txt
package.json
index.html
README.md
public/
  jenos-logo.png
src/
  main.jsx
  App.jsx
  styles.css
```

## Ejecución en StackBlitz

Abrir el repositorio en:

```txt
https://stackblitz.com/github/TU_USUARIO/jenos-pizza-prototipo?startScript=dev
```

## Logo

El logo debe estar en:

```txt
public/jenos-logo.png
```

Puedes reemplazar el archivo `jenos-logo.png` por el logo oficial manteniendo exactamente el mismo nombre.
