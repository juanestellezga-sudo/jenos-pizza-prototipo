# Jeno's Pizza - Prototipo Mobile

Prototipo funcional sin base de datos para simular:
- Ingreso del cliente.
- Creación de pedido.
- Confirmación de orden.
- Línea de tiempo del pedido.
- Finalización y retorno al menú inicial.

## Ejecutar en StackBlitz
1. Crea un proyecto React.
2. Copia estos archivos.
3. Reemplaza `src/App.jsx`.
4. Sube el logo oficial a `public/jenos-logo.png`.

## Publicar
- Vercel: importar el repositorio desde GitHub.
- Netlify: ejecutar `npm run build` y subir la carpeta `dist`.

## Importante
La app no guarda datos. Todo funciona en memoria usando estado de React.
